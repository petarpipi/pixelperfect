# Upwork portfolio entry

**Title:** PixelPerfect — Figma to React Finance Dashboard

**Description:**

Implemented a responsive Northstar Finance dashboard from original Figma screen exports using React, TypeScript and Tailwind CSS. The interface includes Overview, Transactions and Analytics pages, interactive charts, searchable and sortable transactions, category and date filters, validated dialogs and browser-local persistence. Financial summaries update from fictional EUR transaction data. Desktop and mobile layouts were compared with the supplied design references and checked with TypeScript, Vitest, Playwright and axe-core.

This is an independent portfolio demonstration with fictional data, created to showcase Figma-to-code implementation and frontend engineering.

**Role:** Frontend implementation engineer

**Technologies:** React · TypeScript · Vite · Tailwind CSS · React Router · Recharts · Lucide React · Vitest · Playwright · axe-core

**Features:**

- Responsive desktop and mobile UI based on supplied Figma exports.
- Interactive financial charts and derived metrics.
- Search, filters, sorting, pagination and CSV export.
- Validated transaction creation, details and deletion.
- Browser-local persistence, loading and empty states.
- Automated functional, responsive and accessibility checks.
